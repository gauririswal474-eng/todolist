# MERN To-Do List App (MongoDB Task)

- `backend/`: Part 1, Node.js + Express + MongoDB API. See `backend/Readme.md`.
- `frontend/`: Part 2, React frontend integrated with the API. See `frontend/Readme.md`.

## Quick start
```
# terminal 1
cd backend && npm install && cp .env.example .env && npm run dev

# terminal 2
cd frontend && npm install && cp .env.example .env && npm run dev
```
